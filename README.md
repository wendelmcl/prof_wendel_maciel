# Prof. Wendel Maciel

Repositório com exemplos, exercícios e projetos desenvolvidos durante minha atuação como professor do curso de Sistemas de Informação no Centro Universitário Católica de Quixadá (Unicatólica).

## Objetivo

Disponibilizar materiais práticos utilizados em disciplinas da graduação, reunindo exemplos de programação, algoritmos, estruturas de dados, desenvolvimento web, orientação a objetos e desenvolvimento mobile.
